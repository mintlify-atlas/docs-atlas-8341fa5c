This guide walks you through creating a simple procedural mesh using the Realtime Mesh Component. You will build a two-sided triangle with vertex colors — the canonical RMC "hello world."

<Tabs>
  <Tab title="C++">

<Steps>

<Step title="Create an actor class">

Create a new C++ class inheriting from `ARealtimeMeshActor`. In your header file:

```cpp MyProceduralMeshActor.h
#pragma once

#include "CoreMinimal.h"
#include "RealtimeMeshActor.h"
#include "MyProceduralMeshActor.generated.h"

UCLASS()
class MYPROJECT_API AMyProceduralMeshActor : public ARealtimeMeshActor
{
    GENERATED_BODY()

protected:
    virtual void OnGenerateMesh_Implementation() override;
};
```

</Step>

<Step title="Include the required headers">

In your `.cpp` file, include the RMC headers:

```cpp MyProceduralMeshActor.cpp
#include "MyProceduralMeshActor.h"
#include "RealtimeMeshSimple.h"

using namespace RealtimeMesh;
```

</Step>

<Step title="Implement OnGenerateMesh">

Implement `OnGenerateMesh_Implementation`. This is called whenever the mesh needs to be rebuilt:

```cpp MyProceduralMeshActor.cpp
void AMyProceduralMeshActor::OnGenerateMesh_Implementation()
{
    Super::OnGenerateMesh_Implementation();

    // Initialize to URealtimeMeshSimple — the standard mesh type
    URealtimeMeshSimple* RealtimeMesh =
        GetRealtimeMeshComponent()->InitializeRealtimeMesh<URealtimeMeshSimple>();

    // StreamSet holds all vertex/index buffers
    FRealtimeMeshStreamSet StreamSet;

    // Builder with: uint16 indices, FPackedNormal tangents, FVector2DHalf UVs, 1 UV channel
    TRealtimeMeshBuilderLocal<uint16, FPackedNormal, FVector2DHalf, 1> Builder(StreamSet);

    // Enable the data streams we want
    Builder.EnableTangents();
    Builder.EnableTexCoords();
    Builder.EnableColors();
    Builder.EnablePolyGroups(); // allows multiple sections per stream set

    // Add vertices with position, normal, tangent, color, UV
    int32 V0 = Builder.AddVertex(FVector3f(-50.0f, 0.0f, 0.0f))
        .SetNormalAndTangent(FVector3f(0.0f, -1.0f, 0.0f), FVector3f(1.0f, 0.0f, 0.0f))
        .SetColor(FColor::Red)
        .SetTexCoord(FVector2f(0.0f, 0.0f));

    int32 V1 = Builder.AddVertex(FVector3f(0.0f, 0.0f, 100.0f))
        .SetNormalAndTangent(FVector3f(0.0f, -1.0f, 0.0f), FVector3f(1.0f, 0.0f, 0.0f))
        .SetColor(FColor::Green)
        .SetTexCoord(FVector2f(0.5f, 1.0f));

    int32 V2 = Builder.AddVertex(FVector3f(50.0f, 0.0f, 0.0f))
        .SetNormalAndTangent(FVector3f(0.0f, -1.0f, 0.0f), FVector3f(1.0f, 0.0f, 0.0f))
        .SetColor(FColor::Blue)
        .SetTexCoord(FVector2f(1.0f, 0.0f));

    // Add triangles — the last argument is the poly group index (maps to a material section)
    Builder.AddTriangle(V0, V1, V2, 0); // front face → poly group 0
    Builder.AddTriangle(V2, V1, V0, 1); // back face  → poly group 1

    // Set up material slots
    RealtimeMesh->SetupMaterialSlot(0, "PrimaryMaterial");
    RealtimeMesh->SetupMaterialSlot(1, "SecondaryMaterial");

    // Create the section group key — identifies this group within LOD 0
    const FRealtimeMeshSectionGroupKey GroupKey =
        FRealtimeMeshSectionGroupKey::Create(0, FName("TestTriangle"));

    // Create section keys tied to poly groups
    const FRealtimeMeshSectionKey Section0 =
        FRealtimeMeshSectionKey::CreateForPolyGroup(GroupKey, 0);
    const FRealtimeMeshSectionKey Section1 =
        FRealtimeMeshSectionKey::CreateForPolyGroup(GroupKey, 1);

    // Upload the stream set to the GPU
    RealtimeMesh->CreateSectionGroup(GroupKey, StreamSet);

    // Assign each poly group section to its material slot
    RealtimeMesh->UpdateSectionConfig(Section0, FRealtimeMeshSectionConfig(0));
    RealtimeMesh->UpdateSectionConfig(Section1, FRealtimeMeshSectionConfig(1));
}
```

</Step>

<Step title="Add a material">

In the editor, select your actor and assign materials to the **PrimaryMaterial** and **SecondaryMaterial** slots in the Details panel. Any material works — use a simple vertex color material to see the red/green/blue gradient.

</Step>

<Step title="Place the actor in the level">

Compile your project, then drag your `AMyProceduralMeshActor` class from the Content Browser into the level. The triangle will appear immediately.

</Step>

</Steps>

<Tip>
  `ARealtimeMeshActor` also exposes `bDeferGeneration` and `bFrozen` properties. Set `bDeferGeneration = true` to avoid triggering `OnGenerateMesh` on every construction script call while dragging in the editor.
</Tip>

  </Tab>

  <Tab title="Blueprint">

<Steps>

<Step title="Create a Blueprint class">

In the Content Browser, create a new **Blueprint Class** and set the parent class to **RealtimeMeshActor**. Name it `BP_MyMesh`.

</Step>

<Step title="Override OnGenerateMesh">

Open the Blueprint editor. In the **My Blueprint** panel, find **Functions** → **Override** → select **OnGenerateMesh**. This event fires whenever the mesh needs to be rebuilt.

</Step>

<Step title="Build the mesh using MakeMeshBuilder">

From the **OnGenerateMesh** event, call **MakeMeshBuilder** on `self`. Configure it:

- **Wanted Tangents**: Normal
- **Wanted Tex Coords**: Normal  
- **Wants 32 Bit Indices**: false
- **Wanted Poly Group Type**: Normal
- **Wants Colors**: true
- **Wanted Tex Coord Channels**: 1

</Step>

<Step title="Add vertices and triangles">

On the builder, call:
- **AddVertex** with a position → call **Set Normal And Tangent**, **Set Color**, **Set Tex Coord** on the result
- Repeat for each vertex
- Call **AddTriangle** with three vertex indices and a poly group index

</Step>

<Step title="Create the section group">

Get the **Realtime Mesh Component** → call **Initialize Realtime Mesh (Simple)** → then call **Create Section Group** with a **Section Group Key** and a **Stream Set** (from **Make Stream Set** + the builder's output).

</Step>

</Steps>

  </Tab>
</Tabs>

## What you built

You created a two-sided triangle procedural mesh using the `TRealtimeMeshBuilderLocal` API (C++) or `MakeMeshBuilder` (Blueprint). The key concepts illustrated:

- `URealtimeMeshSimple` — the standard mesh data object
- `FRealtimeMeshStreamSet` — the container for typed vertex/index buffers
- `TRealtimeMeshBuilderLocal` — a type-safe builder that fills the stream set
- `FRealtimeMeshSectionGroupKey` + `FRealtimeMeshSectionKey` — hierarchical identifiers for the mesh's LOD → SectionGroup → Section tree
- Poly groups — a way to have multiple material sections within a single stream set
