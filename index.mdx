## Why Realtime Mesh Component?

The RMC has been trusted in production for 6+ years — used by individuals, universities, and Fortune 500 companies in shipped games and real-time applications. It provides a clean, efficient API for everything from simple model loading at runtime to procedurally-generating entire worlds.

<CardGroup cols={2}>
  <Card title="High Performance" icon="bolt">
    Optimized rendering pipeline with batched GPU updates. Dramatically more efficient than ProceduralMeshComponent for dynamic geometry.
  </Card>
  <Card title="LOD Support" icon="layer-group">
    Full Level of Detail support for procedural meshes. Define multiple LOD levels to reduce GPU load at distance.
  </Card>
  <Card title="Blueprint Ready" icon="diagram-project">
    Complete Blueprint API for creating and updating mesh geometry without writing a line of C++.
  </Card>
  <Card title="Collision Support" icon="shield">
    Automatic complex and simple collision generation from mesh data, with async cooking via the Chaos physics engine.
  </Card>
  <Card title="Nanite Support" icon="cube">
    First-class Nanite integration for virtualized geometry, enabling high-polygon procedural meshes with no performance penalty.
  </Card>
  <Card title="Lumen Integration" icon="sun">
    Distance field and card representation support for full Lumen global illumination on runtime-generated geometry.
  </Card>
  <Card title="Network Replication" icon="network-wired">
    Built-in support for replicating mesh components across the network in multiplayer games.
  </Card>
  <Card title="Type-Safe Stream API" icon="code">
    Flexible, type-safe stream builder API for advanced C++ mesh construction with compile-time type checking.
  </Card>
</CardGroup>
